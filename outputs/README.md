# outputs/ — Generated Pipeline Outputs

This directory contains all CSV and JSON files produced by the analytics scripts.
Most files here are git-ignored (see `.gitignore`).

## Files Generated and Their Sources

| File | Generated By | Description |
|------|-------------|-------------|
| `data_quality_report.json` | `analytics/validate_dataset.py` | Data quality metrics and schema mapping |
| `job_skill_matrix.csv` | `analytics/build_vectors.py` | Binary job-by-skill feature matrix |
| `job_skillgroup_matrix.csv` | `analytics/build_vectors.py` | Binary job-by-skill-group feature matrix |
| `job_family_assignments.csv` | `analytics/cluster_job_families.py` | job_id → cluster_id mapping (k=4) |
| `job_family_summary.csv` | `analytics/cluster_job_families.py` | Cluster sizes and top skills per job family |
| `skill_group_assignments.csv` | `analytics/cluster_skill_groups.py` | canonical_skill → group_id mapping (k=9) |
| `skill_group_summary.csv` | `analytics/cluster_skill_groups.py` | Group sizes and representative skills |
| `competence_matrix_numeric.csv` | `analytics/build_competence_matrix.py` | 4×9 matrix of prevalence percentages |
| `competence_matrix_labels.csv` | `analytics/build_competence_matrix.py` | 4×9 matrix with Low/Medium/High labels |
| `cluster_evaluation.json` | `analytics/evaluate_clusters.py` | Elbow data and silhouette scores |
| `skill_frequency.csv` | Exported from Hive | Skill name + distinct post count |
| `job_skills.csv` | Exported from Hive / Pig output | Flat job_id, skill_name pairs |

## Execution Order

Files must be generated in this order:

1. `data_quality_report.json` — validate_dataset.py
2. `job_skill_matrix.csv` / `job_skillgroup_matrix.csv` — build_vectors.py
3. `job_family_assignments.csv` / `job_family_summary.csv` — cluster_job_families.py
4. `skill_group_assignments.csv` / `skill_group_summary.csv` — cluster_skill_groups.py
5. `competence_matrix_*.csv` — build_competence_matrix.py
6. `cluster_evaluation.json` — evaluate_clusters.py

Visualizations are generated last by `analytics/visualize.py`.
